# Team Brief (for AI Mentor/Judge Matching)

## Goal
Build an **AI-First Autonomous Learning System**, not an AI-assisted learning platform.

## Core Problem
The problem is **not** generating quizzes, chatbots, or lessons.

The system must autonomously answer:

- What does the learner know?
- What competency has been achieved?
- What evidence is still missing?
- What knowledge gaps exist?
- What learning task should come next?
- When should the learner be reassessed?
- How should the Learner Model evolve over time?

## Design Philosophy

- AI is the decision-making core.
- Removing AI makes the system largely unusable.
- Humans only provide data, monitor exceptions, and improve the system.

## AI Loop

Evidence Collection
→ Competency Assessment
→ Knowledge Gap Detection
→ Learner Model Update
→ Learning Task Generation
→ Recommendation
→ Continuous Evaluation
→ Repeat

## System Components

- Learner Model
- Competency Framework
- Assessment Engine
- Evidence Store
- Knowledge Graph
- Recommendation Engine
- Continuous Evaluation Engine

## Problem Framing Principles

We intentionally avoid framing around:
- Features (Quiz, Chatbot, Lesson Generator)
- Human workflows
- User convenience

Instead, we frame around:
- Autonomous decision making
- AI reasoning
- System state evolution
- Continuous competency assessment
